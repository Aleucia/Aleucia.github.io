Aleucia — Hash Generator

Use this to compute the password hash for a new character.
The hash is derived with PBKDF2-SHA256 (100 000 iterations).
Paste the result into the CHARACTERS array in assets/js/auth.js.

⚠ Do not deploy this page. Keep it local / offline. 

// Hash will appear here

Algorithm: PBKDF2 · Hash: SHA-256 · Iterations: 100 000 · Output: 256 bits (hex)
Salt: characterName.toLowerCase() + "-aleucia-vault-2026"
Password is normalised to lowercase + trimmed before hashing.
